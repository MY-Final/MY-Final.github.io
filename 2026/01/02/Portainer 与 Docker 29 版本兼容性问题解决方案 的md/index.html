1. Docker 升级至 29 后出现的 Local 环境不可用问题

在 Docker 升级至 29.x 后，Portainer 可能无法连接到本地 Docker 环境，提示：

Environment local is unreachable

这是由于 Docker API 最低版本要求变化，Portainer 无法正常访问 Docker Engine API 所致。
